# rcmd

[English](README.md)

個人的に作った、ちょっとしたツールです。bashのキーボードショートカット
（`bind -x`）を管理するためのターミナルUIです。コマンドを登録してCtrl/Altキーに
割り当てると、nano風のTUIで一覧・編集・削除ができます。毎回`source ~/.bashrc`を
思い出さなくても済むようにしたかったのが動機です。

自分用に作ったものなので、粗い部分もあると思います。IssueやPR歓迎です。

> **注意:** rcmdはbash専用です（bashの`bind -x`とreadlineに依存しています）。
> 今のところUbuntuでのみ動作確認をしています。

## できること

- 任意のシェルコマンドをCtrl/Altキーに割り当て（`Ctrl+X` → `5`のような
  2ストロークの組み合わせも含む）
- 追加・編集・削除・検索を1つのTUIで
- ショートカット一覧をJSONとしてインポート/エクスポート
- すでに使われているキーを上書きする前に、できる限り警告を出そうとします
  ——他のrcmdショートカットとの重複だけでなく、readlineの標準バインド
  （例：履歴検索の`Ctrl+R`）との衝突も、`bind -X`で実際にシェル上で有効な
  ものを調べてチェックします
- `Ctrl+C` / `Ctrl+D` / `Ctrl+Z`は割り当てできません。すでにシェル自身が
  使っているためです（SIGINT / EOF / SIGTSTP）
- 一度セットアップすれば、変更はすぐに反映されます——手動での
  `source ~/.bashrc`は不要です

## 必要なもの

- Go 1.24以上（ビルド用）
- bash

## インストール

```bash
git clone https://github.com/sltomato/rcmd.git
cd rcmd
go build -o rcmd .
```

できあがった`rcmd`バイナリを、`PATH`が通っている場所に置いてください。例えば：

```bash
sudo mv rcmd /usr/local/bin/
```

## セットアップ

以下を一度だけ実行してください：

```bash
rcmd init
```

これにより、`~/.bashrc`に小さなブロックが追加されます：

- `eval "$(rcmd export)"` — 登録済みのショートカットを実際の`bind -x`
  バインドとして読み込みます
- `rcmd`をラップするシェル関数 — バイナリを包み込むことで、`rcmd ls`を
  実行すると自動的に`~/.bashrc`を再読み込みし、行った変更を自分で
  `source`しなくても反映させます

今開いているシェルにも一度だけ反映させてください：

```bash
source ~/.bashrc
```

これ以降、`rcmd ls`が自動的に同期を保ってくれます。

## 使い方

```bash
rcmd ls
```

TUIが開きます。そこから：

| キー | 動作 |
|---|---|
| `↑`/`↓` | 移動 |
| `Ctrl+N` | 新規ショートカットを追加 |
| `Ctrl+E` | 選択中のショートカットを編集 |
| `Ctrl+D` | 選択中のショートカットを削除 |
| `Ctrl+W` | 検索 |
| `Ctrl+O` | ショートカットをJSONファイルへエクスポート |
| `Ctrl+R` | JSONファイルからショートカットをインポート |
| `Ctrl+Q` | 終了 |
| マウスクリック | 行を選択 / 選択中の行の`[Edit]` `[Delete]`をクリック |
| マウスホイール | スクロール |

ショートカットを追加する際は、割り当てたいキーを押した後、プレビュー画面で
確定してください（別のキーを押せば、代わりにそのキーを試すことができます）。

## 仕組み

ショートカットは`~/.config/rcmd/config.json`に保存されます。`rcmd export`は
これを`bind -x`コマンドに変換し、（`rcmd init`によって`~/.bashrc`に追加された）
`eval "$(rcmd export)"`が、新しいシェルが起動するたびにこれをbashへ読み込みます。
